# Notices and provenance

Scarlet Recomp is a work-in-progress native Windows static-recompilation port
of Pokémon Scarlet.

## Upstream architecture

This repository is a fork of **Denkishi/ssbu-recomp (OpenSmash-Ultimate)** and
retains its Git history. Code copied or adapted from that project remains under
the GNU General Public License version 3 as provided in `LICENSE`.

Upstream:
- https://github.com/Denkishi/ssbu-recomp

## Scarlet reverse-engineering source

Game-specific knowledge and selected MIT-licensed implementation work are being
ported from:
- https://github.com/xruanzin/scarlet_pc

That project itself contains work derived from LAS Recomp. Its MIT notice is
preserved in `LICENSE-LASRecomp`.

## Game files

No Pokémon Scarlet executable, assets, keys, firmware, decrypted Nintendo code,
or other proprietary game data should be committed to this repository.
Generated code must be produced locally from a user's own legally obtained dump.
